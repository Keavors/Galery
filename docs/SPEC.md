# Техзадание: Галерея

> Единственный источник правды по проекту. Если решение меняется — оно меняется здесь,
> а не в переписке. Раньше документ жил артефактом на claude.ai; теперь он лежит в
> репозитории, рядом с кодом, и меняется теми же коммитами.
>
> Папка `docs/` — только для разработки: в APK ничего отсюда не попадает.

Своя галерея вместо штатной самсунговской: фото из любого стороннего приложения
открывается здесь и листается по соседям, лента масштабируется двумя пальцами от
отдельных снимков до целых лет, а при просмотре с экрана исчезает вообще всё.

Согласовано 30 августа 2026, последнее изменение 1 сентября 2026 — правило «назад»
после открытия извне, действия над папками, хранение без Room, одиннадцатый этап,
единицы размера файлов, выключенные папки в ленте, метки на плитке.

| | |
| --- | --- |
| Репозиторий | `https://github.com/Keavors/Galery.git` |
| Пакет | `com.keavors.gallery` |
| min / target / compile | 33 / 36 / 37 |
| Библиотека | ≈5000 файлов |
| Устройство | Android 16, One UI 8 |

Уровни зума ленты: **2** колонки (крупно) → **4** (день) → **7** (день) →
**12** (месяц и год) → **25** (год).

Везде ниже «фото» означает и фотографию, и видео. Там, где что-то относится только к
одному из двух, это сказано прямо.

## 01. Решения, которые больше не обсуждаем

Всё, что было развилкой, закрыто. Здесь зафиксировано, что выбрано и чем за это платим —
чтобы через три недели не переигрывать по памяти.

| Вопрос | Решение | Цена решения |
| --- | --- | --- |
| Доступ к файлам | `READ_MEDIA_IMAGES`, `READ_MEDIA_VIDEO`, `ACCESS_MEDIA_LOCATION` плюс `MANAGE_MEDIA` | Удаление, корзина, избранное и поворот работают без системного диалога на каждое действие. `MANAGE_MEDIA` выдаётся один раз вручную в системных настройках — приложение проведёт туда за руку. |
| Корзина | Системная, `IS_TRASHED` | Срок 30 дней задан Android и не настраивается. Взамен: файлы не двигаются с места, удаление и восстановление мгновенны даже для гигабайтных видео, удалённое видно и в самсунговской галерее. |
| Скрытые альбомы | Настоящее скрытие: перенос в приватную папку приложения | Файлы исчезают из MediaStore — их не видит ни одна другая программа. Но перенос больших файлов занимает время, а удаление приложения унесёт их с собой: обязательны предупреждение и кнопка экспорта. |
| Редактор | Свой, на Compose Canvas и ColorMatrix | Больше кода, чем при готовой библиотеке, зато единый стиль, живой код и никакой зависимости от заброшенного проекта на старых вьюхах. |
| UI | Jetpack Compose + Material 3 | Отличается от PassVault и PdfReader, совпадает с MagicCalculator. Иначе зум ленты, shared-element переходы и редактор обошлись бы втрое дороже. |
| minSdk 33 | Android 13 и новее | Ни одной ветки кода ради старых моделей разрешений, системный выбор языка приложения и predictive back — из коробки. |
| Play Store | Не публикуемся | Можно свободно пользоваться `MANAGE_MEDIA` и не подстраиваться под политики. |

## 02. Стек и устройство проекта

Один модуль `:app`, как в остальных проектах. Версии зафиксированы в каталоге
`gradle/libs.versions.toml`.

| Задача | Чем решаем | Почему именно так |
| --- | --- | --- |
| Интерфейс | Compose, Material 3 | Анимации, зум сетки и shared-element переходы пишутся естественно, а не вручную. |
| Картинки | Coil 3 | Нативен для Compose, свои кэши в памяти и на диске, HEIC / AVIF / GIF из коробки. |
| Зум фото | Telephoto `zoomable-image-coil` | Пинч, двойной тап, инерция, границы и подгрузка огромных снимков по частям. Готовая интеграция с `HorizontalPager`. |
| Видео | Media3 / ExoPlayer | HEVC, HDR, точный seek, PiP. |
| Обрезка видео | Media3 Transformer | Аппаратное перекодирование без сторонних сборок FFmpeg. |
| Индекс | В памяти. Room не используем | Индекс — зеркало MediaStore, где нет ни одного поля, принадлежащего нам: избранное пишется в MediaStore, корзина системная. Вторая база на диске не даёт ничего. Своё — свои альбомы, закреплённое, скрытое, выбранные обложки, сейф — это несколько сотен байт, которые читаются в память целиком и никогда не запрашиваются выборкой: они лежат одним JSON-документом в DataStore. Схема, миграции и кодогенерация вокруг строки — это церемония, а не польза. |
| Синхронизация | `ContentObserver` над MediaStore | Снял фото — оно появилось в ленте само, без ручного обновления. |
| Настройки | DataStore Preferences | Асинхронно, типобезопасно, легко экспортировать в файл. |
| Фоновые задачи | WorkManager | Переиндексация, чистка кэша, проверка сроков корзины. |
| Внедрение зависимостей | Свой `AppContainer` | Для одного модуля Hilt — лишний вес и лишняя генерация кода. |

## 03. Четыре механизма, ради которых всё затевается

Остальное — обычная работа. Эти четыре куска определяют, получится приложение или нет,
поэтому расписаны отдельно.

### Открытие извне и поиск соседей

Приложение объявляет `ACTION_VIEW` для `image/*` и `video/*`. Приходящий URI бывает очень
разным, поэтому работает каскад: как только очередная стратегия дала результат, остальные
не запускаются.

1. **URI уже из MediaStore.** Идеальный случай. Берём `bucket_id`, запрашиваем всю папку,
   ставим курсор на нужный индекс. Соседи листаются мгновенно.
2. **Чужой FileProvider.** Telegram, браузер, файловый менеджер. Пробуем
   `MediaStore.getMediaUri()` — если система знает соответствие, дальше как в первом случае.
3. **Сопоставление по признакам.** Достаём имя, размер и дату через `DocumentsContract`
   или `OpenableColumns` и ищем совпадение в своём индексе. Нашли — знаем папку, знаем соседей.
4. **Файл вне библиотеки.** Приватный кэш мессенджера: соседей физически не существует.
   Открываем одиночный просмотр молча, все функции кроме листания работают.

**Деталь, которая решает удобство.** Приложение запускается как `singleTask` и ловит новый
интент в `onNewIntent` — поэтому внешнее открытие всегда попадает в уже работающий
экземпляр, а не плодит копии.

Стек экранов при этом не выдумывается. Интент заменяет то, чем приложение было занято,
поэтому под фотографией остаётся ровно то, что было на экране до неё: **та же папка — если
открыта была именно она**, и ничего — во всех остальных случаях. «Назад» из просмотра
оставляет тебя в этой папке, следующее «назад» — в ленте «Снимки», и только оттуда
приложение сворачивается. Если открытой была другая папка, другая вкладка или приложение
вовсе не работало, «назад» из фотографии ведёт сразу в «Снимки»: несуществующая папка,
собранная по `bucket_id` ради одного шага назад, — это шаг, которого никто не делал.

**Скорость.** Фотография должна появляться одновременно с интерфейсом, а не после него.
Поэтому: превью запускается в момент чтения интента — раньше, чем экран успевает
скомпоноваться; оно рисуется под фотографией как самостоятельная картинка, а не как
подсказка кэшу; ExoPlayer строится только когда смотрят видео; перечитывание библиотеки
ждёт, пока пришедшую фотографию не закроют.

### Шторки, от которых ничего не дёргается

Требование «фото не должно сдвинуться ни на пиксель» выполняется не аккуратностью, а
конструкцией. Фото и видео с самого начала лежат на полноэкранном контейнере:
`setDecorFitsSystemWindows(false)`, режим выреза `shortEdges`. Системные бары и наши шторки —
оверлей поверх этого контейнера.

- Скрытие и показ меняют только прозрачность шторок и видимость системных баров. Разметка
  контейнера не пересчитывается вообще — сдвигу неоткуда взяться.
- Системные бары убираются через `WindowInsetsControllerCompat.hide(systemBars())` с
  поведением `BEHAVIOR_SHOW_TRANSIENT_BARS_BY_SWIPE`: уходят и часы с зарядкой сверху, и
  кнопки навигации снизу.
- Отступы шторок берутся из insets, которые известны и когда бары спрятаны, — поэтому
  кнопки не заезжают под вырез камеры.
- Ровно этот приём уже работает в PdfReader, так что риск здесь нулевой.

### Зум ленты двумя пальцами

Самая сложная часть интерфейса. Наивная реализация — просто менять число колонок по жесту —
выглядит как рывок и теряет место, на которое ты смотрел.

- Во время жеста вся сетка масштабируется графически, без перекладывания элементов:
  движение идёт за пальцами один в один.
- На отпускании притягиваемся к ближайшему уровню и перекладываем сетку с кроссфейдом.
- Элемент под центром жеста — якорь: после перекладки он остаётся под пальцем, а не улетает.
- Заголовки групп меняют масштаб вместе с уровнем: на 12 колонках день превращается в
  «Август 2026», на 25 — в «2026».

### Права, корзина и избранное без диалогов

Android разрешает изменять чужие медиафайлы только через системное подтверждение — если
только приложению не выдан `MANAGE_MEDIA`. Это отдельный экран в системных настройках, куда
пользователь заходит один раз сам.

- При первом запуске просим обычные разрешения на чтение. Если выдан частичный доступ
  («выбранные фото»), объясняем, почему галерее нужен полный, и ведём в настройки.
- Отдельным шагом предлагаем выдать `MANAGE_MEDIA` — с честным объяснением, что это даёт и
  что без него всё работает, но с подтверждением на каждое удаление.
- Удаление ставит `IS_TRASHED`. Из поля `date_expires` считаем, сколько дней осталось, и
  показываем это на плитке в корзине.
- Сердечко пишет `IS_FAVORITE` в MediaStore — так избранное видно и другим галереям.
- Перемещение файла и переименование папки — это тоже чужие файлы: сначала
  `createWriteRequest` на всю пачку, и только потом запись. С `MANAGE_MEDIA` система
  соглашается молча.

## 04. Четыре вкладки

### Снимки

- Лента по датам, новые сверху, липкие заголовки с датой, днём недели и количеством.
- Пять уровней зума двумя пальцами, квадратные плитки с обрезкой; мозаика с сохранением
  пропорций — опция.
- На плитке: длительность видео, сердечко у избранного, метки GIF и RAW. Метки Motion
  Photo на плитке нет и не будет: отличить motion photo от обычного JPEG можно только
  дочитав файл до конца, а это шестьсот чтений файлов на один экран сетки. Motion
  photo распознаётся в просмотрщике, по долгому нажатию, где речь идёт ровно об
  одном файле.
- Быстрый скроллбар справа с подписью даты под пальцем.
- Кнопка «в самый верх» внизу по центру — появляется во время прокрутки и живёт три
  секунды после остановки.
- Мультивыбор долгим нажатием и протягиванием пальца, действия над выделенным: поделиться,
  удалить, в избранное, переместить, копировать, скрыть.
- Поиск по имени, папке, дате и типу.

### Альбомы

- Альбом = папка на диске. Плюс виртуальные: Избранное, Видео, Камера, Скриншоты,
  Недавно удалённые.
- Свои альбомы, не привязанные к папкам: один снимок может лежать в нескольких.
- Действия: закрепить наверх, скрыть, переименовать, удалить, сменить обложку, создать,
  переместить и копировать снимки. Папка — это место на диске, поэтому переименование папки
  переносит все её файлы, а удаление отправляет их в системную корзину; свой альбом — это
  список идентификаторов, и его удаление не трогает ни одного файла.
- Скрытые альбомы за PIN или биометрией — файлы физически переносятся в приватную папку и
  пропадают из всех остальных программ. Отдельно: экспорт наружу и предупреждение о том,
  что удаление приложения унесёт их с собой.

### Корзина

- Сетка удалённого с отметкой «осталось N дней» на каждой плитке.
- Восстановить, удалить окончательно, восстановить всё, очистить корзину — с отдельным
  подтверждением на необратимое.
- Мультивыбор работает так же, как в ленте.

## 05. Просмотрщик

Главный экран приложения по количеству времени, проведённого в нём. Всё остальное — способ
до него добраться.

| | | |
| --- | --- | --- |
| Верхняя шторка | Назад, название, меню | Слева стрелка выхода. По центру дата и имя файла. Справа три точки: «Сведения» и «Копировать в буфер обмена». |
| Нижняя шторка | Пять действий | Сердечко (заполняется при нажатии), «Редактировать», «Поделиться», «Удалить» с подтверждением и кнопка принудительного поворота. |
| Жесты | Тап, двойной тап, свайпы | Тап убирает вообще всё, повторный возвращает. Двойной тап — 1× → 2× → 1× к точке касания. Свайп вниз закрывает, фото уходит за пальцем. Свайп вверх открывает сведения. |
| Видео | Свои контролы | Play / пауза, полоса с превью кадра, звук, скорость, покадровый шаг. Прячутся вместе со шторками. Автозапуск и звук по умолчанию выключены. |
| Сведения | Всё, что есть в файле | Имя, путь, размер, разрешение и мегапиксели, даты съёмки и изменения, камера, объектив, ISO, выдержка, диафрагма, фокусное, вспышка, баланс белого, координаты с картой. Для видео — кодек, битрейт, частота кадров, длительность. |
| Переход | Плитка разворачивается в фото | Плитка растёт в фотографию: не shared-element в смысле фреймворка, а коробка просмотрщика, которая начинается ровно на месте и в размере нажатой плитки. Обратный путь — закрытие свайпом ровно в свою плитку — ещё не сделан. |

## 06. Редактор

Уровень 3: геометрия, цвет, разметка. Всё на Compose Canvas — это не «с нуля» в плохом
смысле, Compose даёт готовые примитивы для рисования и цветовых матриц.

| Группа | Инструменты |
| --- | --- |
| Геометрия | Кадрирование со свободными и фиксированными пропорциями, поворот на 90°, отражение, выравнивание горизонта с шагом в градус, сетка третей. |
| Свет и цвет | Яркость, контраст, экспозиция, тени, света, насыщенность, температура, оттенок, резкость, виньетка. |
| Фильтры | Набор пресетов с превью на самом снимке и регулировкой силы. |
| Разметка | Кисть с выбором цвета и толщины, ластик, текст со шрифтом и цветом, стикеры и эмодзи, размытие и пикселизация участка. |
| Видео | Обрезка начала и конца по таймлайну с кадрами, экспорт через Media3 Transformer. |
| Общее | Отмена и повтор по шагам, сравнение с оригиналом по долгому нажатию, сброс всего. |

**Как не съесть память на 108-мегапиксельном снимке.** Редактируем уменьшенную копию,
которая гарантированно влезает в экран, а весь список применённых операций храним отдельно.
При сохранении применяем этот список к оригиналу в полном разрешении, в фоне, с прогрессом.
Так интерфейс остаётся мгновенным, а качество не теряется.

## 07. Настройки

Настраивается всё, до чего дотягиваются руки. Появляться они будут волнами вместе с фичами,
а не полсотни переключателей сразу, половина из которых ни на что не влияет. У экрана есть
поиск и сброс отдельного раздела.

**Внешний вид**
- Тема: светлая, тёмная, системная, AMOLED-чёрная
- Акцентный цвет и цвет из обоев (Material You)
- Отступ между плитками, 0–8
- Скругление углов плиток
- Скорость анимаций и полное их отключение
- Размер шрифта интерфейса

**Снимки**
- Уровень зума по умолчанию
- Сортировка: дата съёмки, дата изменения, имя, размер
- Направление сортировки
- Форма плиток: квадрат или мозаика
- Какие папки показывать — это скрытие альбома на вкладке «Альбомы»: выключенная
  папка уходит и из ленты. Отдельный переключатель возвращает их в ленту, ничего
  не раскрывая
- Показывать ли видео, скриншоты, загрузки
- Что рисовать на плитке
- Формат заголовков групп

**Просмотр**
- Шторки при открытии: видны или скрыты
- Автоскрытие и его задержка
- Действие свайпа вниз и вверх
- Двойной тап: зум или ничего
- Максимальный масштаб
- Зацикливать листание
- Максимальная яркость
- Держать экран включённым
- Что показывать в заголовке

**Видео**
- Автовоспроизведение
- Звук при открытии
- Повтор
- Скорость по умолчанию
- Картинка в картинке
- Продолжать с места остановки

**Корзина и удаление**
- Подтверждение: окно или отмена в Snackbar
- Отдельное подтверждение необратимого удаления
- Показывать оставшиеся дни

**Безопасность**
- PIN или биометрия на скрытые альбомы
- Блокировка всего приложения
- Прятать содержимое в списке недавних
- Экспорт скрытого наружу

**Редактор**
- Сохранять копию или перезаписывать (или спрашивать)
- Качество JPEG при сохранении
- Куда класть результат
- Сохранять ли EXIF оригинала

**Общие**
- Язык: русский, английский, системный
- Формат даты и времени
- Единицы размера файлов: по умолчанию тысячи и «КБ», как считает сама Android и
  как продаётся диск; переключатель даёт 1024 и «КиБ». Смешивать нельзя — 1024
  байта это КиБ, а КБ это тысяча
- Размер кэша миниатюр и его очистка
- Экспорт и импорт всех настроек в файл
- Разрешения и статус доступа к медиа
- О программе, версия, ссылка на репозиторий

## 08. Этапы

Порядок не случайный: каждый следующий этап опирается на предыдущий, а самое рискованное
вынесено вперёд, чтобы неприятности вскрылись рано. Каждый этап заканчивается коммитом в
`main` и работающей сборкой.

**00. Каркас.** Проект, каталог версий, `.gitignore`, тема и типографика, четыре вкладки
внизу, первый пуш в репозиторий.
*Готово, когда:* приложение ставится на телефон и переключает четыре пустых экрана.

**01. Доступ к медиа.** Запрос разрешений с внятными экранами, отдельный случай частичного
доступа, `MANAGE_MEDIA`, чтение MediaStore одним запросом, индекс, наблюдатель изменений.
*Готово, когда:* все 5000 файлов проиндексированы, новое фото с камеры появляется в базе само.

**02. Лента «Снимки».** Сетка по датам, липкие заголовки, пять уровней зума с якорем,
скроллбар, кнопка «наверх», мультивыбор, поиск.
*Готово, когда:* лента прокручивается без рывков и зумится двумя пальцами от 2 до 25 колонок.

**03. Просмотрщик.** Пейджер, зум, исчезающие шторки, обе панели с кнопками, видео с
контролами, сведения, поделиться, копировать.
*Готово, когда:* при тапе исчезает вообще всё и ничего никуда не сдвигается.

**04. Открытие извне.** Интент-фильтры, каскад разрешения URI, поиск соседей, правило
«назад» из раздела 03, `ACTION_PICK`.
*Готово, когда:* фото из файлового менеджера и из Telegram листается по соседям, а «назад»
возвращает туда, где ты был до него.

**05. Избранное и корзина.** Сердечко с записью в MediaStore, вкладка корзины, оставшиеся
дни, восстановление, необратимое удаление.
*Готово, когда:* удалённое лежит в корзине и восстанавливается на то же место.

**06. Альбомы.** Папки, виртуальные альбомы, свои альбомы, все действия над ними — включая
переименование и удаление папки, — перемещение и копирование снимков. Здесь же появляются
первые данные, которых нет в MediaStore: свои альбомы, закреплённое, скрытое, обложки. Они
хранятся одним JSON-документом в DataStore, без Room.
*Готово, когда:* альбом переименовывается, удаляется, закрепляется и меняет обложку, а
снимок перекладывается из папки в папку.

**07. Настройки.** Полный экран с поиском, все переключатели из раздела 07, экспорт и
импорт, языки, темы.
*Готово, когда:* каждая настройка реально влияет на поведение, а не лежит мёртвой.

**08. Скрытые альбомы.** PIN и биометрия, перенос в приватную папку, экспорт наружу,
блокировка приложения, скрытие в недавних.
*Готово, когда:* скрытые файлы не видны ни в самсунговской галерее, ни в файловом менеджере.

**09. Редактор.** Кроп и геометрия, коррекции, фильтры, кисть, текст, размытие, обрезка
видео, сохранение в полном разрешении.
*Готово, когда:* отредактированный снимок сохраняется без потери разрешения и с сохранённым EXIF.

**10. Полировка.** Motion Photo, слайдшоу, карта по координатам, иконка, анимации, прогон по
производительности, README. Картинка в картинке ушла на одиннадцатый этап, к остальному плееру.
*Готово, когда:* приложением приятно пользоваться каждый день и штатная галерея больше не нужна.

**11. Видеоплеер.** Плеер сейчас умеет play, паузу, полосу перемотки и звук — это меньше,
чем обещано в разделе 05. Здесь он дорастает до обещанного: превью кадра на полосе,
скорость воспроизведения, покадровый шаг, продолжение с места остановки и картинка в
картинке. Остальные удобства — жесты громкости и яркости, блокировка касаний, выбор
дорожки — обсуждаем перед началом этапа и дописываем сюда, а не по ходу дела.
*Готово, когда:* видео удобнее смотреть здесь, чем в штатном плеере.

## 09. Что может пойти не так

Честный список. Для каждого пункта — что делаем, если не выйдет.

| Риск | Оценка | Страховка |
| --- | --- | --- |
| Плавный зум ленты с якорем | высокий | Сначала делаем рабочую смену уровней без анимации, убеждаемся, что данные и позиции считаются верно, и только потом добавляем масштабирование и кроссфейд. |
| Соседи из произвольного URI | средний | Каскад из четырёх стратегий и честный одиночный режим в конце. Проверим на реальных источниках: файловый менеджер, Telegram, браузер, WhatsApp. |
| Потеря скрытых файлов при удалении приложения | высокий | Предупреждение при первом использовании, постоянная кнопка экспорта, напоминание в настройках. Это следствие выбранного способа скрытия, устранить его нельзя — только сделать очевидным. |
| Память в редакторе на больших снимках | средний | Редактирование по уменьшенной копии, применение операций к оригиналу в фоне. |
| Motion Photo — недокументированный формат | средний | Если маркер не распознан, файл открывается как обычное фото. Ничего не ломается, просто не проигрывается встроенное видео. |
| Перенос файлов при переименовании папки | средний | Переименование — это `RELATIVE_PATH` у каждого файла, и оно может выйти наполовину. Считаем перенесённые и сказываем «перенесено N из M» вместе с причиной; ни одно действие над файлами не молчит. |
| Новые ограничения свежих версий Android | низкий | Собираемся против API 37, но целимся в 36 — ровно ту версию, что стоит на телефоне. Значит, приложение ведёт себя так, как ты видишь своими глазами, а не по правилам ещё не вышедшей системы. |
| Я не вижу результат своими глазами | средний | Собирать я могу. Но вёрстку и анимации приходится описывать словами. Если разрешишь отладку по USB, я буду ставить сборки и снимать скриншоты сам, и цикл доводки ускорится в разы. |

## 10. Процесс

| | |
| --- | --- |
| Репозиторий | `https://github.com/Keavors/Galery.git`, HTTPS через Windows credential manager — как в PdfReader и Calculator. |
| Ветки | Коммитим прямо в `main` мелкими осмысленными коммитами, каждый сразу пушим. |
| Язык | Английский везде: сообщения коммитов, комментарии в коде, названия. Интерфейс — русский по умолчанию. Общение — по-русски. |
| Сообщения коммитов | Прозой, объясняющей почему, а не списком файлов. |
| Комментарии в коде | Объясняют причину решения, а не пересказывают код. |
| Сборка | `JAVA_HOME="D:/AndroidStudio/jbr" ./gradlew assembleDebug testDebugUnitTest lintDebug`. Собираю сам перед каждым коммитом — сломанный код до тебя не доедет. |
| Тесты | JVM-юнит-тесты на всю чистую логику. Тест не сторожит код, который приложение не вызывает: если правило написано дважды, оно выносится в одно место и тестируется там. |
| CI | GitHub Actions: на каждый пуш собирает debug-сборку и гоняет тесты, готовый APK можно скачать со страницы репозитория. |
| Запуск | Ты, через Android Studio. Если разрешишь отладку по USB — смогу ставить и проверять сам. |
| Правило про ошибки | Операция, которая может не получиться, обязана об этом сказать пользователю. Молчаливый провал — это баг. |
| Правило про настройки | Не добавляем настройку, которая ни на что не влияет. |

## 11. Сознательно отложено

Не «забыли», а решили не делать сейчас. Вернёмся, когда основное будет работать каждый день.

- **Планшетные и двухпанельные раскладки.** Сетка подстраивается под ширину, но специальных
  layout'ов для больших экранов не делаем — планшета нет.
- **Полноценный RAW-конвертер.** DNG показываем через системный декодер, а если конкретный
  файл не открывается — встроенное превью и все метаданные. Конвертер с обработкой сырых
  данных — это отдельный проект.
- **Виджет на рабочий стол и плитка быстрых настроек.** После десятого этапа.
- **Синхронизация и облако.** Приложение принципиально офлайновое.
- **Поиск по содержимому снимков.** Распознавание объектов и лиц — не в этом проекте.
